# Chirag Deviputra — DevOps Portfolio

Agency-inspired typography and animated project showcases in charcoal (#13151f) and porcelain (#e9ecee), with title decoding, a Three.js Lorenz background and sand particle words.

Five repository-backed projects, including Dockerised Web App, Personal Agent Corrupter, Lenovo LOQ Experience, Docker E-Commerce and Azure GitOps Deployment Dashboard.

**Windows:** extract, run `portfolio-web/start.bat`, and open http://127.0.0.1:5000. For an existing installation, restart Flask and press Ctrl+F5. Keep Motion on to see the effects.

Full setup, editing, source notes and email instructions are in `portfolio-web/README.md`. Current screenshots are in `previews`.
